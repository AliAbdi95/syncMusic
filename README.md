# Sync Music App – نسخه نمونه اولیه (وای‌فای + انتقال فایل)

اپلیکیشن اندروید برای پخش همزمان موسیقی روی چند گوشی داخل یک شبکه وای‌فای.

## ویژگی‌های این نسخه

- یک نفر **Host** می‌شود و کد ۶ رقمی + IP خود را نمایش می‌دهد
- بقیه با وارد کردن کد و IP به سشن وصل می‌شوند
- **Host یک‌بار آهنگ را از اینترنت دانلود می‌کند** و سپس فایل را مستقیماً روی وای‌فای به همه Clientها می‌فرستد
- پیشرفت ارسال/دریافت فایل نمایش داده می‌شود
- Host دستور پخش همزمان می‌دهد (با ۳ ثانیه بافر)
- همگام‌سازی ساعت با محاسبه offset
- کلاینت‌های جدیدی که بعداً وصل شوند هم فایل را دریافت می‌کنند

## چطور اجرا کنید

1. پوشه `SyncMusicApp` را در Android Studio باز کنید (Open → انتخاب پوشه)
2. صبر کنید Gradle sync تمام شود
3. یک یا چند امولاتور / گوشی واقعی وصل کنید (همه باید روی یک وای‌فای باشند)
4. Run کنید

### تست روی دو گوشی واقعی

1. روی گوشی اول → **میزبان شو**
2. کد سشن و IP نمایش داده شده را یادداشت کنید
3. روی گوشی دوم → **ورود به سشن** → کد را وارد کنید → IP Host را وارد کنید
4. روی Host دکمه **دانلود و ارسال آهنگ به کلاینت‌ها** را بزنید
5. صبر کنید:
   - Host دانلود از اینترنت را تمام کند
   - فایل روی وای‌فای به Client ارسال شود (پیشرفت درصد نشان داده می‌شود)
6. وقتی Client نوشت «آهنگ از Host دریافت شد ✓» → روی Host دکمه **پخش همزمان** را بزنید

## محدودیت‌های نسخه فعلی

- IP را باید دستی وارد کرد (مرحله بعدی: NSD برای پیدا کردن خودکار)
- فقط یک آهنگ نمونه از اینترنت (Host دانلود می‌کند)
- هنوز چت، لیست پخش مشترک و حالت اینترنت ندارد
- همگام‌سازی روی شبکه‌های شلوغ ممکن است چند ده میلی‌ثانیه اختلاف داشته باشد
- انتقال فایل روی سوکت متنی+باینری انجام می‌شود (برای فایل‌های خیلی بزرگ بهتر است HTTP جداگانه استفاده شود)

## مراحل بعدی پیشنهادی

1. اضافه کردن Network Service Discovery (NSD) برای پیدا کردن خودکار Host
2. ~~انتقال فایل آهنگ از Host به Client~~ ✅ انجام شد
3. حالت اینترنت با WebSocket + سرور
4. چت ساده
5. لیست پخش مشترک
6. انتخاب آهنگ از گالری/حافظه گوشی Host
