# Sync Music App – نسخه نمونه اولیه (وای‌فای + انتقال فایل)

اپلیکیشن اندروید برای پخش همزمان موسیقی روی چند گوشی داخل یک شبکه وای‌فای.

## چطور بدون Android Studio فایل APK بگیری؟

### روش پیشنهادی: GitHub Actions (رایگان)

1. برو [github.com](https://github.com) و حساب رایگان بساز.
2. روی **New repository** کلیک کن → اسم مثلاً `SyncMusicApp` بگذار → **Public** انتخاب کن → Create.
3. داخل ریپازیتوری روی **uploading an existing file** کلیک کن.
4. همه فایل‌ها و پوشه‌های داخل `SyncMusicApp` رو بکش و رها کن (drag & drop) → Commit changes.
5. برو تب **Actions** (بالای صفحه).
6. روی workflow **Build Debug APK** کلیک کن → **Run workflow** (اگر خودکار شروع نشد).
7. چند دقیقه صبر کن تا سبز بشه.
8. وقتی تموم شد، پایین صفحه قسمت **Artifacts** → فایل **SyncMusic-Debug-APK** رو دانلود کن.
9. فایل zip رو باز کن → `app-debug.apk` رو روی گوشی‌ات کپی و نصب کن  
   (اگر از نصب فایل ناشناس جلوگیری کرد: تنظیمات → امنیت → اجازه نصب از منابع ناشناس).

> نکته: اولین بیلد ممکنه ۸–۱۲ دقیقه طول بکشه چون SDK و dependencyها دانلود می‌شن.

## ویژگی‌های فعلی اپ

- یک نفر **Host** می‌شود و کد ۶ رقمی + IP خود را نمایش می‌دهد
- بقیه با وارد کردن کد و IP به سشن وصل می‌شوند
- Host یک‌بار آهنگ را از اینترنت دانلود می‌کند و فایل را مستقیماً روی وای‌فای به Clientها می‌فرستد
- پیشرفت ارسال/دریافت فایل نمایش داده می‌شود
- پخش همزمان با همگام‌سازی ساعت

## تست روی دو گوشی

1. هر دو گوشی روی **یک وای‌فای** باشند.
2. روی یکی Host شو → کد و IP را یادداشت کن.
3. روی دومی Join کن → کد + IP را وارد کن.
4. روی Host دکمه «دانلود و ارسال آهنگ...» را بزن.
5. صبر کن تا Client بنویسد «آهنگ از Host دریافت شد ✓».
6. روی Host «پخش همزمان» را بزن.

## مراحل بعدی

1. پیدا کردن خودکار Host با NSD
2. حالت اینترنت
3. چت ساده
4. لیست پخش مشترک
5. انتخاب آهنگ از حافظه گوشی
